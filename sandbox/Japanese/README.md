```
行首字母 (50-4=46)

            --------------------------------
            |     |      |      |     |      |      |      |
            a    i      u    e    o     ya   yu    yo
           あ   い  う   え   お   や   ゆ    よ
             | By Sound type
         ---------------------
         |             |                 |
        清音      濁音          半濁音
         (Seion)  (Dakuon)   (Handakuon)
         | By Writing system  ...
     --------------------------
     |                  |                  |
     片假名        平假名        羅馬字

```

## Terms explained

- Leading character → 首字母／行首字母
	-- Refers to the first vowel or consonant-vowel row used to organize Japanese kana.
- Seion (清音) → 清音
	-- Basic kana sounds without voicing marks.
	-- Example: か (ka), さ (sa), た (ta)
- Dakuon (濁音) → 濁音
	-- Voiced sounds marked with ゛.
	-- Example: が (ga), ざ (za), だ (da)
- Handakuon (半濁音) → 半濁音
	-- Semi-voiced sounds marked with ゜.
	-- Example: ぱ (pa), ぴ (pi), ぷ (pu)
- Hiragana (ひらがな) → 平假名
	-- Used for native Japanese words and grammar.
- Katakana (カタカナ) → 片假名
	-- Used mainly for foreign words(外來語), loanwords(外來語), and emphasis(強調語氣).
- Romaji → 羅馬字
	-- Japanese sounds written with the Latin alphabet (e.g., "arigatou").
- Kanji → 漢字
	-- Japanese written borrowed from the Chinese character (e.g., "比例" AKA. "ひれい" AKA. "proportion").
